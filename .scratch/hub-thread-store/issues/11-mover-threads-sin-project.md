# 11: Mover Threads sin Project

**What to build:** Un Thread sin Project tiene una carpeta temporal con su propio repositorio en el Hub. Sus checkpoints se suben, y se mueve entre máquinas igual que un Thread con Project. Ver spec, «Repositorio git del Hub y checkpoints».

**Blocked by:** 08.

**Status:** ready-for-agent

- [ ] Cada Thread sin Project tiene un repositorio del Hub para su carpeta temporal, con la misma autorización que un Project de su Space.
- [ ] La subida de checkpoints, los diffs con la máquina apagada, el move y los cambios recuperados funcionan igual que con un Project.
- [ ] Tests en el testkit con dos Environments.
