# Self-hosted single-owner installation on an independent fork

We build a self-hosted product where one Owner runs one Installation and invites others into it, not a public multi-tenant SaaS: no self sign-up, billing or tenant isolation between strangers. We also run as an independent fork of pingdotgg/t3code rather than one that tracks upstream, so we may change T3 Code's core model (for example, a Project is no longer bound to one Environment, see `GLOSSARY.md`), accepting that upstream improvements must be ported by hand.
